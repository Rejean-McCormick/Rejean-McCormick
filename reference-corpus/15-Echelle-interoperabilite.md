# Échelle, instances souveraines et interopérabilité

L’architecture est destinée à pouvoir être composée à plusieurs échelles :

**une personne → une équipe → une communauté → une école → une organisation → une municipalité → une université → un gouvernement → un réseau international**

Cela ne signifie pas qu’une seule instance doit absorber tout le monde.

## Le modèle recherché

> **protocoles communs, instances souveraines**

Des instances indépendantes peuvent conserver :

- leur gouvernance;
- leurs identités;
- leurs données;
- leurs politiques;
- leurs langues;
- leurs contraintes locales.

L’interopérabilité est obtenue par des contrats, des artefacts portables et des protocoles explicites plutôt que par une base de données centrale universelle.

## Worlds

Les mécanismes de Worlds ajoutent une isolation de contexte à cette logique : différents environnements peuvent exister sur une infrastructure commune tout en conservant des frontières explicites.
