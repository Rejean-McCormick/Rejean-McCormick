# Le problème : transformer l’abondance en capacité collective

Les sociétés contemporaines n’ont pas seulement un problème d’information. Elles disposent déjà d’une quantité immense de connaissances, d’expérience, de créativité, de données, de travailleurs qualifiés et de personnes prêtes à contribuer.

Le problème apparaît dans les **passages** :

- une contribution ne devient pas automatiquement une connaissance fiable;
- une connaissance ne rejoint pas automatiquement la bonne décision;
- une décision ne devient pas automatiquement une exécution claire;
- une exécution ne produit pas automatiquement une mémoire réutilisable;
- une société peut donc recommencer les mêmes cycles sans accumuler suffisamment de capacité.

kOA traite ces passages comme un problème d’infrastructure.

## La boucle

**Sources → connaissance → délibération → décision → exécution → résultats → leçons → mémoire → nouvelle connaissance**

La valeur n’est pas seulement dans chacun des nœuds. Elle est dans la continuité entre eux.

## Ce que cela change

Une organisation devient plus capable lorsqu’elle peut :

- retrouver ce qu’elle sait déjà;
- identifier qui possède une expertise pertinente;
- rendre les raisons d’une décision inspectables;
- attribuer les responsabilités d’exécution;
- préserver la provenance et les résultats;
- réutiliser ce qui a été appris dans le prochain cycle.
