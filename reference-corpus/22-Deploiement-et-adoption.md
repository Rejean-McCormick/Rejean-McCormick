# Déploiement et adoption

L’architecture ne suppose pas qu’une organisation doive tout adopter d’un seul coup.

Une trajectoire de déploiement peut commencer par :

**un problème → un workflow → une équipe → une instance → une fédération éventuelle**

## Déploiement technique

Les outils de déploiement couvrent plusieurs surfaces :

- Koali comme environnement hôte;
- Koali Spaces pour l’expérience;
- Capsule Manager pour empaqueter et exploiter Konnaxion;
- profils réseau;
- backup / restore / rollback;
- SecurityDiag et LevelUpDiag pour les contrôles;
- Worlds pour l’isolation de contextes.

## Adoption sociale

L’adoption n’est pas uniquement technique.

Elle peut passer par :

- démonstrateurs;
- scénarios;
- enseignement UCKK;
- chansons;
- récits;
- King Klown;
- documentation institutionnelle;
- communautés d’usage;
- contribution open source.

Ces voies parlent à des publics différents mais peuvent conduire vers la même infrastructure.
