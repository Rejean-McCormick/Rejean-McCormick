# Le kOA Digital Ecosystem

Le kOA Digital Ecosystem est une infrastructure sociotechnique organisée autour d’un cycle complet de capacité collective :

**connaissance → délibération → décision → exécution → mémoire**

Il n’est pas conçu comme une application monolithique. Il relie plusieurs systèmes dont les responsabilités restent séparées.

## Les grandes autorités

| Système | Autorité principale |
|---|---|
| **Koali / kOA-Linux** | hôte, identité, confiance, politiques, ressources, lifecycle, artifacts, release, backup/recovery |
| **Koali Spaces** | composition de l’expérience utilisateur; aucune autorité métier |
| **Konnaxion** | espace civique/public : contribution, délibération, consultation, expertise, culture, collaboration |
| **Orgo** | exécution opérationnelle : signaux, cas, workflows, tâches, responsabilités, résultats |
| **Kristal** | connaissance structurée, provenance, validation, artefacts épistémiques |
| **Da’at** | adaptation / frontière entre protocole d’interaction et Kristal |
| **Interaction Kernel** | protocole inter-systèmes : commandes, requêtes, événements, reçus et réconciliation |
| **UCKK** | apprentissage et publication externe optionnelle; pas une dépendance du cœur |
| **King Klown** | narration et mobilisation; aucune autorité technique sur les systèmes |

## Pourquoi séparer les autorités

Une intégration ne doit pas permettre à un système de devenir secrètement propriétaire des données ou décisions d’un autre. Cette séparation facilite :

- l’audit;
- le remplacement d’un composant;
- le fonctionnement dégradé;
- l’autonomie des instances;
- la sécurité;
- la compréhension de qui peut décider quoi.
